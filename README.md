# Ecommerce Delivery Analysis

## Project Overview
This project analyzes e-commerce sales, profit, and delivery performance using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Git and GitHub

## Dataset
- Total records: 180,519
- Original columns: 53

## Key Findings
- Late delivery percentage: 57.28%
- Average delivery delay: 0.57 days
- Highest-sales category: Fishing
- Highest-profit category: Fishing

## Analysis Performed
- Data cleaning
- Delivery performance analysis
- Sales and profit analysis
- Monthly trend analysis
